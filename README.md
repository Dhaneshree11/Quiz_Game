# Quiz_Game
 An advanced console-based Quiz Game developed in Java,  demonstrating core software engineering principles including  Object-Oriented Programming (OOP), Multithreading, File Handling,  and Design Patterns. Features a real-time  15-second countdown timer, multiple question types (MCQ &amp; True/False), persistent score saving, and a high score tracker.
